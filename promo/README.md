# MacBook Pro 宣发片 · 重制版

一支 19 秒、快节奏、苹果风格的 MacBook 宣发片。整支片子就是一份工程文本：
[`macbook-promo.txt`](macbook-promo.txt)。

## 怎么看

1. 顶栏「导入」→ 列表里点 **macbook-promo.txt** —— 素材由本地服务按代码里的相对路径直接从磁盘读入，
   工程一并应用（一次点击，不需要选文件）。
2. 或者手动来：把本目录里的素材整段拖进「资源」页，再把 `macbook-promo.txt` 粘进「代码」页。
3. 点走带上的 **▶** 看整片。

## 分镜（快节奏）

| 时间 | 画面 | 手段 |
| :-- | :-- | :-- |
| 0.0s | 黑场里一个小影子，从深处冲进来 | 位置 + 旋转 + 缩放，`v=[0:0.1,0.35:2.8,0.65:0.9,1:0.85]` 猛加速收尾 |
| 2.3s | 掀盖，背景同时切成彩色光斑 | `s` 开合 + 逐拍背景 `bgmedia=底图彩色` + 曝光脉冲 |
| 3.1s | 主标题错峰登场：**"MacBook" 从左冲入、"Pro" 从上砸下**，都带缩放过冲 | 拆成两个文字对象，各自 `sc 0.5→1.15→1` + 旋转 + 变速 |
| 4.4s | 副标"轻 · 薄 · 强"从一点放大弹出 | `sc 0.15→1` |
| 6.1s | 屏幕切代码，背景转冷 | `f=代码` + `bgmedia=底图极速` |
| 8.6s | **360° 甩身 + 拉远**，背景换动态光 | `a=[0,-360,0]` + 背景视频 |
| 10.6s | 转回正面，屏幕切进动态片段 | `f=开场` + 视频轨 `.clip` |
| 11.6s | 同一素材**裁剪 + 慢放**一小段 | `@macbook.clip b … in=2.60 out=3.40 v=[0:0.5,0.5:2,1:0.5]` |
| 12.4s | 猛推近，屏幕是编辑器本体 | `sc 1→1.18` |
| 15.6s | 拉回，片尾卡，灯光转暖 | `bgmedia=底图片尾` |
| 16.0s | "简辑" 带着旋转砸下，副标放大进场 | 文字对象 `sc 0.3→1` + `a=[0,14,0]` |

**摄像机全程不动。** 冲击力来自三处：机身的冲镜 / 旋转 / 缩放、逐拍切换的背景、
以及拆成多块各自带着缩放与过冲登场的标题。背景是**媒体底图**（图片或视频，`bgmedia=资源别名`），
它同样属于关键帧，所以每一拍能换一套。

## 目录内容

- `macbook-promo.txt` —— 工程文件本体（这支片子的"源码"）
- `macOS 壁纸.png` / `代码编辑器.png` / `编辑器界面.png` / `片尾.png` —— 屏幕四张画面
- `开场动画.mp4` —— 屏幕上的 6 秒动态素材
- `底图-开场.png` / `底图-彩色.png` / `底图-极速.png` / `底图-片尾.png` —— 四张电影感背景
- `背景动画.mp4` —— 8 秒动态背景（用在 360° 甩身那一段）
- `MacBook Pro 宣发片.mp4` —— 用软件自己的「导出 MP4」通道出的成片
- `frames/` —— 关键帧静帧：`01`–`06` 来自「导出当前帧」，`07`–`08`（360° 甩身、动态片段）
  从成片里取，因为这两拍的画面是视频，只有走 MP4 那一趟才有

## 成片

顶栏「导出」→「整片 MP4」会**逐帧求值后编码**（不是录屏）：每一帧都先 `seek`、等屏幕视频与
背景视频落到属于那一帧的源画面、再渲染、再编码。所以 360° 甩身那一段、屏幕上放动态片段的那一段、
背景是动态光的那一段，全都在成片里。文件：`MacBook Pro 宣发片.mp4`（H.264 / 30fps / 1080p）。

## 已知限制

- **MP4 没有音频**：时间线上还没有音频轨，导出只有画面。
- **导出慢，且窗口要保持在前台**：一帧要等一次屏幕视频 seek，浏览器在后台还会节流
  `requestAnimationFrame`。19 秒的片子在这台机器上约 20 分钟。
- **文字没有透明度动画**：淡入淡出用缩放（`sc 0.15→1` / `1→0.15`）代替，看着像"弹出 / 缩回"。
