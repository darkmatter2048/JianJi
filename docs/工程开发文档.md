# 简辑（UAE2 Studio）工程开发文档

> 本文档面向二次开发：说明工程文件（DSL）的完整语法、内置设备的默认信息，以及代码中散落的默认值。
> 版本对应仓库内 `src/lib/projectText.ts` 的 `HEADER = '# 简辑 · 工程文件 v1'`。

---

## 1. 总览

简辑是一个 Rotato 风格的三维视频编辑器。界面四区：**素材区 / 编辑区（3D 视口）/ 参数区 / 时间线**。核心约定：

- **每个对象一条独立时间线**（没有单独的"相机时间线"）。
- 按 **`D`** 在播放头给当前选中对象打一个关键帧。
- **变速** = 从上一帧到当前帧这一段的速度（Bézier 曲线），挂在"到达的这一帧"上。
- **摄像机固定**：工程文件不描述摄像机，导入工程时会把机位复位到默认取景。

### 技术栈

| 层 | 选型 |
|---|---|
| 构建 | Vite 8 + TypeScript 5.9（strict）|
| UI | React 19 + zustand 5 + Radix primitives + lucide-react，无 Tailwind，CSS 变量在 `kit.css` |
| 3D | three.js 0.186 + @react-three/fiber 9 + drei 10 |
| 导出 | WebCodecs + `mp4-muxer`（逐帧求值后编码 H.264）|

### 关键目录

```
src/
  lib/
    projectText.ts    工程文件 DSL（读 / 写 / 应用）
    assets.ts         设备模型注册表（MODEL_ASSETS）+ 铰链 / 屏幕规格
    presets.ts        相机 / 机位 / 材质预设，对象配色
    speedCurve.ts     变速曲线
    fonts.ts          3D 文字字体
    keyframes.ts      关键帧求值 / 隐藏 / 显隐
    animation.ts      相机 / 帧求值
  store/editorStore.ts  zustand 状态（对象 / 时间线 / 场景 / 项目 / 相机）
  components/          UI 与 3D 视口
public/models/<id>/   每个设备一个文件夹：scene.gltf + scene.bin + textures/ + license.txt
```

## 2. 工程文件语法（DSL）

文件是**面向行**的：一行一件事，`#` 开头是注释，字段用空白分隔的 `key=value`，值内部**不能有空格**（列表用 `[…]`，含空格的路径/名字用双引号 `"…"`，引号内 `\"` 转义）。目的是可读、可 diff、可手写。

### 2.1 文件头

```
# 简辑 · 工程文件 v1
```

### 2.2 项目设置

```
project = 未命名项目          # 工程名，可取到行尾（可含空格）
aspect = 16:9                 # 16:9 | 9:16 | 1:1 | 4:5 | 21:9
fps = 30                      # 帧率，1..120
```

### 2.3 资源声明（`alias = …`）

一行声明一个资源，别名后续用于引用。

```
# 素材库（名字 = 相对本文件的路径；blob 内容不在文件里）
cover = media:素材/封面.png
clip  = media:"assets/intro clip.mp4" 2.5s 1920x1080
mac   = model:macbook-pro-13-2020
```

- `media:<路径>`：图片 / 视频 / 音频素材。路径含空格时加引号；**相对工程文件所在目录**解析。
  行尾可带 `<秒>s` 与 `<宽>x<高>`，这两个字段是**注释性**的（不参与解析，仅供阅读）。
- `model:<资产id>`：设备模型，`资产id` 见第 3 节注册表。

### 2.4 对象声明

对象声明后跟着它的关键帧行（`@别名 …`）。

```
mac   = model:macbook-pro-13-2020 "MacBook" color=#f5a524 appear=0
shot  = image:cover "封面图" color=#4c8dff
clip1 = video:clip "开场" appear=0.5
title = text "标题" color=#e879f9
```

- `model:<资产id>`：3D 设备；`"名称"` 可省略（省略时用注册表里的默认名）。
- `image:<素材别名|路径>` / `video:<素材别名|路径>`：图片 / 视频平面（在场景里作为独立 3D 对象）。
- `text`：3D 文字对象。
- 公共可选字段：
  - `color=#hex`：时间轴轨道颜色（不是材质颜色）。
  - `appear=<秒>`：对象在此时间之后才出现（默认 0）。
  - `off`：对象初始隐藏。

### 2.5 文字设置（对象声明下一行的缩进 `text …`）

```
title = text "标题"
  text font=wenkai size=0.3 color=#ffffff opacity=1 align=center spacing=0 lineheight=1.25 wrap=0 content="你好"
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `font` | 字体 id：`wenkai` / `dejavu` / `dejavu-bold` | `wenkai` |
| `size` | 字号（场景单位）| 0.3 |
| `color` | 颜色 `#hex` | `#ffffff` |
| `opacity` | 不透明度 0..1 | 1 |
| `align` | `left` / `center` / `right` | `center` |
| `spacing` | 字间距 | 0 |
| `lineheight` | 行高倍数 | 1.25 |
| `wrap` | 最大宽度（换行），0 = 不换行 | 0 |
| `content` | 文本内容（引号包裹）| — |

### 2.6 关键帧（`@别名 …`）

```
@mac t=0.00 p=[0,0,0] s=120.0 a=[0,-20,0] f=cover v=1 vis=fade
@mac t=1.50 p=[0,0.3,0] s=105.0 a=[0,0,0] sc=[1,1,1] f=- v=1.25 hid=fade
```

| 字段 | 含义 |
|---|---|
| `t` | 时间（秒）|
| `p=[x,y,z]` | 位置 |
| `s=<度>` | 屏幕（盖子）开合角度；无铰链对象写作 `-` |
| `a=[rx,ry,rz]` | 旋转（欧拉角，度，XYZ 顺序）|
| `sc=[sx,sy,sz]` | 缩放；等于 `[1,1,1]` 时省略不写 |
| `f=<素材别名>` | 屏幕贴图（指向 2.3 里声明的素材别名）；无贴图写作 `-` |
| `v=<速度>` | 该帧**到达段**的变速，见 2.8 |
| `hid` | 本帧隐藏（瞬间消失）|
| `hid=fade` | 本帧隐藏（渐隐）|
| `vis=fade` | 本帧显示（渐显）|
| `scene=…` | 场景变更标记，见 2.9 |
| `chain` | 重绘链：把这一帧的状态写进该对象后续所有关键帧 |

> 隐显模式属于"到达的这一帧"：两帧不一致就消失/重现，所以只需在到达帧标注。

### 2.7 视频片段（`@别名.clip …`）

```
@clip1.clip c1 m=clip t=0.5 in=0 out=2.8 v=1
```

| 字段 | 含义 |
|---|---|
| 第二个词 `c1` | 片段 id（供 UI 选中）|
| `m=<素材别名>` | 引用的视频素材 |
| `t=<秒>` | 片段在对象时间轴上的开始时间 |
| `in=<秒>` / `out=<秒>` | 在源素材里的入点 / 出点 |
| `v=<速度>` | 变速 |

### 2.8 变速 `v`

- 平直：`v=1`（恒定倍率）。
- 曲线：`v=[t:v,t:v,…]`，`t` 是段内归一化位置 0..1，`v` 是倍率（上限见 `DEFAULT_MAX_SPEED = 4`）。

```
v=1.25
v=[0:1,0.5:0.2,1:1]
```

### 2.9 场景（`scene=…`）

场景信息**属于关键帧**，写在关键帧的 `scene=` 字段里（逗号分隔，因为空格会结束字段）。写文件时**只在场景变化时**才重复写出该字段，没写 = 沿用上一帧。

解析器额外接受一个 `scene …` 头行（空格分隔）作为**全局兜底**（供手写文件用；导出器不产生它，只写关键帧级字段）：

```
@mac t=0 p=[0,0,0] s=120 a=[0,0,0] f=- v=1 scene=bg=gradient,color=#0b0f16,grad=#1d2534>#05070b,angle=160,env=1,exp=1,shadow=0.55:2.6
@mac t=1 p=[0,0,0] s=120 a=[0,0,0] f=- v=1 scene=bg=media,bgmedia=backdrop,bgfit=cover,bgoverlay=0.25,bgblur=0
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `bg` | `solid` / `gradient` / `none`（透明）/ `media` | `gradient` |
| `color` | 纯色背景 `#hex` | `#0b0f16` |
| `grad=#from>#to` | 渐变起止色 | `#1d2534>#05070b` |
| `angle` | 渐变角度（度）| 160 |
| `env` | 环境光强度 | 1 |
| `exp` | 曝光 | 1 |
| `shadow=<不透明度>:<模糊>` | 阴影（`0.55:2.6`）；不写 = 关闭 | 开 0.55/2.6 |
| `bgmedia=<素材别名>` | 媒体背景（指向 2.3 的别名）| — |
| `bgfit` | `cover` / `contain` | `cover` |
| `bgoverlay` | 媒体背景叠加遮罩 0..1 | 0.25 |
| `bgblur` | 背景模糊 | 0 |

> `scene=-` 表示"这一帧不键任何场景"。

### 2.10 摄像机

**摄像机固定，工程文件不描述它。** 写入 `@camera` 会被解析器拒绝并报错：
`摄像机是固定的，工程文件里不需要 @camera`。应用一份工程时，机位与编辑视口都会复位到默认取景（见 4.1）。

### 2.11 完整示例

```
# 简辑 · 工程文件 v1

# 项目
project = 宣传片
aspect = 16:9
fps = 30

# 素材库
cover = media:素材/封面.png
intro = media:素材/intro.mp4 3.20s 1920x1080

# 3D 模型
mac = model:macbook-pro-13-2020 "MacBook" color=#f5a524

@mac t=0.00 p=[0,0,0] s=0 a=[0,-20,0] f=cover v=1 hid=fade scene=bg=gradient,color=#0b0f16,grad=#1d2534>#05070b,angle=160,env=1,exp=1,shadow=0.55:2.6
@mac t=0.80 p=[0,0,0] s=120 a=[0,-20,0] f=cover v=[0:0.8,1:1] vis=fade
@mac.clip c1 m=intro t=0 in=0 out=2.8 v=1
```

## 3. 内置设备信息（`MODEL_ASSETS`）

设备模型放在 `public/models/<id>/`，文件夹名 = 资产 id；`lib/assets.ts` 里每条一个 `ModelAsset`。

### 3.1 `ModelAsset` 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | string | 资产 id，工程文件 `model:<id>` 用它引用 |
| `name` | string | 设备库显示名 |
| `url` | string | glTF 路径（相对站点根）|
| `note` / `size` | string | 卡片说明 / 体积 |
| `hinge?` | HingeSpec | 可开合的盖子（见 3.2）|
| `screen?` | ScreenSpec | 可贴图的屏幕（见 3.3）|
| `form?` | `'phone' \| 'laptop'` | 设备库图标形态，默认 `laptop` |
| `orientation?` | `[x,y,z]` | 欧拉角（度，XYZ），在自动适配**之前**施加，让朝向异常的模型面朝相机 |
| `keywords?` | string[] | 设备库搜索词 |

### 3.2 `HingeSpec`（开合铰链）

| 字段 | 含义 | 默认 |
|---|---|---|
| `node` | glTF 里承载盖子的节点名（其原点须在转轴上）| — |
| `maxDeg` | 铰链物理上限（度）| — |
| `fullDeg` | "打开"吸附到的角度（度）| — |
| `axis?` | 转轴 `'x' \| 'y' \| 'z'` | `x` |
| `sign?` | 旋转方向 `1 \| -1` | `-1`（MacBook 约定）|
| `offset?` | 烘焙姿态对应的 `openDeg` 值（即转角为 0 的位置）| 0 |

**实际施加的转角**：`sign · (openDeg − offset)°`，绕 `axis` 轴。

> 注意：three.js 的 GLTFLoader 会把节点名里的 `.` 等字符去掉（`Cube.001_1` → `Cube001_1`）。`prepareModel` 用与 loader 相同的规则（仅保留 `[A-Za-z0-9_]`）做消毒后匹配，所以注册表里写原始导出名即可。

### 3.3 `ScreenSpec`（可贴图屏幕）

| 字段 | 含义 |
|---|---|
| `label` | UI 里显示的屏名 |
| `material` | 屏幕**材质名**（不是网格名）|
| `aspect` | 面板宽高比（宽 / 高），决定素材如何裁切 / 留黑边 |

### 3.4 当前设备表

| 资产 id | 名称 | 铰链 | 屏幕 | 朝向 | 形态 | 体积 |
|---|---|---|---|---|---|---|
| `macbook-pro-13-2020` | MacBook Pro 13" (2020) | `Bevels_2`, max 135 / full 120 | `Material.002`, aspect 1.595 | — | laptop | 5.1 MB |
| `iphone-16-pro-max` | iPhone 16 Pro Max | — | `screen.001`, aspect 0.47 | `[0, 90, 0]` | phone | 2.7 MB |
| `xiaomi-17-pro-max` | 小米 17 Pro Max | — | `glass`, aspect 0.456 | — | phone | 2.2 MB |
| `gaming-laptop` | 游戏本 | `Cube.001_1`, max 180 / full 180, axis `z`, sign `1`, offset `180` | `Material.004`, aspect 2.17 | — | laptop | 12.6 MB |

> 手机屏幕是竖屏（aspect < 1）。游戏本的屏幕材质是 `Material.004`（`Material.010` 是键盘，不要贴错）。

### 3.5 新增一个设备

1. 丢一个文件夹 `public/models/<id>/`，内含 `scene.gltf` + `scene.bin` + `textures/` + `license.txt`。
2. 在 `lib/assets.ts` 追加一条 `ModelAsset`。
3. 用 glTF 查看器找铰链节点（原点在转轴处）与屏幕材质名，填 `hinge.node` / `screen.material`；朝向不对就填 `orientation`。
4. 视口会自动居中、按最长轴缩放到 `FIT_SIZE = 2` 并落到地面，无需手调尺寸。

## 5. 数据模型（关键类型）

### 5.1 变换 `Transform`

```ts
{ position: [x,y,z]; rotation: [rx,ry,rz]; scale: [sx,sy,sz] }
```

旋转是欧拉角（度，XYZ 顺序）；`p=` / `a=` / `sc=` 分别对应三者。

### 5.2 变速 `SpeedCurve` / `SpeedNode`

```ts
interface SpeedNode { id: string; t: number; v: number; inHandle: [number,number]; outHandle: [number,number] }
interface SpeedCurve { nodes: SpeedNode[]; maxSpeed: number }
```

`t ∈ 0..1`（段内归一化），`v` 是倍率，`maxSpeed` 是速度轴上限（默认 4）。

### 5.3 屏幕 `ScreenSettings`

```ts
{
  enabled: boolean
  source: 'image' | 'video'
  src: string | null          // blob: 或 data: URL
  mediaId: string | null
  fileName: string | null
  duration: number
  sourceAspect: number        // 源宽高比
  fit: 'cover' | 'contain' | 'fill' | 'tile'  // 裁剪 / 适应 / 填充 / 平铺
  brightness: number          // 0..3
  rotation: number            // 顺时针角度
  loop: boolean; muted: boolean; rate: number
}
```

`fit` 三种 UI 模式：**平铺 tile**（原尺寸重复）、**裁剪 cover**（等比放大裁剪）、**填充 fill**（拉伸填满）；`contain` 仅工程文本 `f=contain` 兼容保留，不在 UI 暴露。

### 5.4 场景 `SceneSettings`

背景 `background`（type / color / from / to / angle / mediaId / src / source / fit / overlay / blur）+ `envIntensity` + `exposure` + `shadow {enabled, opacity, blur}` + `soundtrackId`。

### 5.5 对象 `SceneObject`

`kind: 'model' | 'media' | 'text'`、`assetId`、`transform`、`visible`、`lid`（铰链）、`screen`、`text`、`material`、`color`（轨道色）、`screenClips`（视频片段）、`keyframes`（关键帧）、`appearAt`。

## 6. 解析与应用的规则（`applyParsedProject`）

1. **模型资源**按资产 id 解析到 `MODEL_ASSETS`；未知 id 会警告并跳过该对象。
2. **媒体资源**按两段匹配：先按工程文件里写的**相对路径**，再按**裸文件名**（去扩展名），这样"只选工程文件"时也能自动从本地素材库按名字兜底补齐。
3. **场景深合并**：`scene=` 字段与全局 `scene` 头、当前场景做深合并（背景、阴影逐字段覆盖），文件只说它关心的字段。
4. **场景兜底**：文件在关键帧上声明房间，不写在头部；取最早一个声明了场景的帧作为全局兜底。
5. **摄像机复位**：应用工程时把 `camera` 与 `view` 都复位到默认取景并 `revision+1`，并清空 `cameraKeyframes` —— 否则"同一份工程"会在残留机位的会话里拍出不同画面。
6. **速度**：`v` 平直或 `(t,v)` 节点；节点自动重新求手柄（`autoSmoothNodes`）。
7. **帧间隔**：相邻关键帧的 `sourceSpan = 时间差`，与编辑器自身重排逻辑一致。

## 7. 常见错误提示（解析器）

| 提示 | 触发 |
|---|---|
| `第 N 行：需要一个 = 或 @ 开头` | 行既非注释、非 `key=value`、非 `@` |
| `第 N 行：@x 之前没有声明过这个对象` | `@` 引用了未声明的别名 |
| `第 N 行：不认识的 @x.y` | 不是 `.clip` 的后缀 |
| `第 N 行：摄像机是固定的，工程文件里不需要 @camera` | 写了 `@camera` |
| `第 N 行：不认识的类型「…」（可用 model / image / video / text / media）` | 声明类型非法 |
| `资源 x = … 不在素材库里，引用它的帧会被跳过` | 媒体资源未在库里匹配到 |
