# 简辑 · AI 视频创作知识库

> 本文件是给 **AI（大模型 / 智能体）** 的创作知识库。你（AI）的任务是：**根据用户的文案/分镜/创意，直接产出一份合法、可播放的「工程文件」文本**，再由编辑器导入并渲染成视频。
>
> 你不需要懂 TypeScript 或内部实现，只需掌握：**① 输出什么格式的文本；② 有哪些现成资源可调用；③ 时间、运动、显隐、变速这些语义怎么算；④ 怎么保证产出合法。**

---

## 0. 一句话任务定义

读入用户需求 → 规划分镜（哪些对象、在哪些时间点、做什么动作、屏幕上放什么）→ 输出一份**工程文件文本**（纯文本，格式见 §2）。

输出永远是一份以 `# 简辑 · 工程文件 v1` 开头的文本。它**即项目本身**：资源声明 + 每个对象的独立时间线。

---

## 1. 心智模型（创作时这样想）

### 1.1 时间
- 一切时间单位是**秒**（不是帧）。字段 `t`、`in`、`out`、`appear` 都用秒。
- `fps`（默认 30）只决定导出时每秒采样多少帧，**不影响**你在文本里写的时间值。写 `t=1.5` 就是 1.5 秒。

### 1.2 对象 = 一条独立时间线
一个项目由若干**对象**组成，每个对象是一条自己的时间线（关键帧序列）。对象类型：
- `model:<资产id>`：3D 设备（手机 / 笔记本），可移动、可旋转、可开合（若有铰链）、可贴屏。
- `image:<素材别名>` / `video:<素材别名>`：图片 / 视频平面（在场景里作为独立 3D 对象）。
- `text`：3D 文字。

### 1.3 关键帧 = 一个"姿势"
关键帧声明"**在 t 秒时，这个对象是什么状态**"：位置 `p`、旋转 `a`、缩放 `sc`、屏幕开合 `s`、屏幕贴图 `f`、以及"从上一帧到这一帧"的变速 `v` 和显隐 `hid/vis`。

**两帧之间是自动插值的**（见 §3.1）：想让对象动起来，就写两个时间点不同的关键帧；中间过程不用写。

### 1.4 相机是固定的
- 摄像机**不可动**、**不可键控**，工程文件里不能出现 `@camera`（会报错）。
- 导出视频用的是固定机位：**正面略俯**（方位 0°、仰角 10°、距离 5.4、FOV 30）。观众看到的是一个固定的正面产品视角。
- 所以"运镜"只能通过**移动/旋转物体本身**来实现（把手机转过来、把笔记本合上等）。

### 1.5 空间
- 三维坐标系：`p=[x,y,z]`，**y=0 是地面**（对象会自动落地），x 左右，z 前后（+z 朝向镜头）。
- 每个设备导入后会自动**居中并按最长轴缩放到 2 个单位**，落到地面。所以 `p=[0,0,0]` = 居中放在镜头正前方地面。
- 旋转 `a=[rx,ry,rz]` 是欧拉角（度，XYZ 顺序）：绕 y 转 = 水平转向（面向/背对镜头），绕 x 转 = 俯仰，绕 z 转 = 翻滚。

## 2. 输出契约：工程文件语言（DSL）

**格式规则（必须遵守）：**
- 一行一件事；`#` 开头是注释。
- 字段是空白分隔的 `key=value`，**值内不能有空格**；列表用 `[a,b,c]`；含空格的路径/名字用双引号 `"…"`（引号内 `\"` 转义）。
- 别名（`alias`）**先声明、后使用**。

### 2.1 文件头（第一行，固定）

```
# 简辑 · 工程文件 v1
```

### 2.2 项目设置

```
project = <工程名，可含空格，取到行尾>
aspect = 16:9          # 16:9 | 9:16 | 1:1 | 4:5 | 21:9
fps = 30               # 1..120，默认 30
```

### 2.3 素材库（声明资源，给别名）

```
cover = media:素材/封面.png            # 图片（路径相对本工程文件；含空格加引号）
intro = media:"assets/intro clip.mp4"  # 视频
```

- `media:<路径>`：图片 / 视频 / 音频素材。行尾可附 `<秒>s` 和 `<宽>x<高>`（如 `3.20s 1920x1080`），**仅供人阅读，不参与解析**。
- 资源别名用于后面的 `f=`（贴屏）和 `@alias.clip`（视频片段）引用。

### 2.4 对象声明

```
mac   = model:macbook-pro-13-2020 "MacBook" color=#f5a524 appear=0
phone = model:iphone-16-pro-max
pic   = image:cover "封面"
clip  = video:intro
title = text "标题"
```

| 类型 | 写法 | 说明 |
|---|---|---|
| 3D 设备 | `alias = model:<资产id> ["名称"]` | 资产 id 见 §4.1 |
| 图片平面 | `alias = image:<素材别名>` | 作为 3D 对象出现在场景 |
| 视频平面 | `alias = video:<素材别名>` | 同上，是视频 |
| 文字 | `alias = text ["名称"]` | 3D 文字，内容在下一行 `text …` |

对象声明可带公共修饰（写在声明行）：
- `color=#hex`：时间轴轨道颜色（非材质颜色）。
- `appear=<秒>`：对象在此时间后才出现（默认 0）。
- `off`：对象初始隐藏。

### 2.5 文字内容（`text` 对象的下一行，缩进）

```
title = text "标题"
  text font=wenkai size=0.3 color=#ffffff opacity=1 align=center spacing=0 lineheight=1.25 wrap=0 content="你好，世界"
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `font` | `wenkai`（中英）/ `dejavu` / `dejavu-bold` | `wenkai` |
| `size` | 字号（场景单位）| 0.3 |
| `color` | 颜色 `#hex` | `#ffffff` |
| `opacity` | 0..1 | 1 |
| `align` | `left`/`center`/`right` | `center` |
| `spacing` | 字间距 | 0 |
| `lineheight` | 行高倍数 | 1.25 |
| `wrap` | 最大宽度（换行），0=不换行 | 0 |
| `content` | 文本（双引号包裹）| — |

### 2.6 关键帧（`@别名 …`）

```
@mac t=0.00 p=[0,0,0] s=120 a=[0,-20,0] f=cover v=1 vis=fade
@mac t=1.50 p=[0,0.3,0] s=105 a=[0,0,0] f=- v=1.25 hid=fade
```

| 字段 | 含义 | 默认/省略 |
|---|---|---|
| `t=<秒>` | 时间 | 0 |
| `p=[x,y,z]` | 位置 | 沿用上一帧 |
| `s=<度>` | 屏幕开合角；**无铰链设备写 `-`** | 沿用 |
| `a=[rx,ry,rz]` | 旋转（度，XYZ）| 沿用 |
| `sc=[sx,sy,sz]` | 缩放；`[1,1,1]` 时可省略 | `[1,1,1]` |
| `f=<素材别名>` | 屏幕贴图；无贴图写 `-` | 沿用 |
| `v=<变速>` | **到达段**变速（见 §2.8）| 1 |
| `hid` / `hid=fade` / `vis=fade` | 显隐（见 §3.3）| 显示 |
| `scene=…` | 场景变更（见 §2.9）| 沿用上一帧 |
| `chain` | 把此帧状态写进后续所有帧 | — |

> **省略即沿用**：某字段没写，就沿用上一帧的值。所以通常第一帧写全，后续帧只写变化的字段。

### 2.7 视频片段（`@别名.clip …`）

给某个对象（通常是设备屏幕）安排一段视频：

```
@mac.clip c1 m=intro t=0 in=0 out=2.8 v=1
```

| 字段 | 含义 |
|---|---|
| 第二个词 `c1` | 片段 id（供 UI 选中，可任意命名）|
| `m=<素材别名>` | 引用的视频素材 |
| `t=<秒>` | 片段在对象时间轴上的开始时间 |
| `in=<秒>` / `out=<秒>` | 源素材入点 / 出点 |
| `v=<变速>` | 变速 |

### 2.8 变速 `v`

`v` 描述**从上一帧到当前这一帧**这一段的播放速度（倍率，上限 4）：
- 平直：`v=1`（匀速）。
- 曲线：`v=[t:v,t:v,…]`，`t` 是段内归一化位置 0..1，`v` 是倍率。

常用预设（可直接抄）：
```
v=1                                  # 匀速
v=[0:0.4,1:1.8]                      # 缓入（起步慢）
v=[0:1.8,1:0.4]                      # 缓出（收尾慢）
v=[0:2.2,0.5:0.35,1:2.2]             # 中间慢放
v=[0:0.35,0.45:2.6,0.75:2.6,1:0.35]  # 子弹时间
```

### 2.9 场景 / 背景（`scene=…`）

背景属于关键帧，写在 `scene=` 字段（逗号分隔）。**只在背景变化时写**，没写就沿用上一帧。第一帧通常写一次全局背景。

```
@mac t=0 p=[0,0,0] s=120 a=[0,0,0] f=- v=1 scene=bg=gradient,color=#0b0f16,grad=#1d2534>#05070b,angle=160,env=1,exp=1,shadow=0.55:2.6
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `bg` | `solid` 纯色 / `gradient` 渐变 / `none` 透明 / `media` 媒体背景 | `gradient` |
| `color` | 纯色 `#hex` | `#0b0f16` |
| `grad=#from>#to` | 渐变起止色 | `#1d2534>#05070b` |
| `angle` | 渐变角度（度）| 160 |
| `env` | 环境光强度 | 1 |
| `exp` | 曝光 | 1 |
| `shadow=<不透明度>:<模糊>` | 阴影；不写=关 | 开 `0.55:2.6` |
| `bgmedia=<素材别名>` | 媒体背景（引用 §2.3 的别名）| — |
| `bgfit` | `cover`/`contain` | `cover` |
| `bgoverlay` | 背景叠加遮罩 0..1 | 0.25 |
| `bgblur` | 背景模糊 | 0 |

## 3. 语义（AI 必须理解，才能写出对的动作）

### 3.1 运动插值
两帧之间，`p`/`a`/`sc`/`s` 是**线性插值**，但进度由该段的**变速曲线 `v` 塑造**：
- `v=1` → 匀速运动。
- `v=[0:0.4,1:1.8]` → 缓入（先慢后快），相当于缓动函数。
- 换句话说：**变速曲线同时就是这段运动的缓动曲线**。

### 3.2 屏幕贴图 / 场景 / 显隐是"跳变"
`f`（贴图）、`scene`（背景）、`hid`（显隐）**不做交叉淡入**，而是在关键帧处**瞬间切换**（到达该帧那一刻生效）。想淡入淡出贴图，用两帧 + `hid=fade`/`vis=fade` 控制对象整体显隐。

### 3.3 显隐 `hid` / `vis`
- `hid`：到这一帧对象**瞬间消失**。
- `hid=fade`：到这一帧对象**渐隐**（消失过程用该段变速曲线做缓动）。
- `vis=fade`：到这一帧对象**渐显**。
- 渐显写法：起始帧 `hid`，结束帧 `vis=fade`（例：`t=0 hid` → `t=0.8 vis=fade` = 0→0.8 秒淡入）。
- 渐隐写法：起始帧不写（或 `vis`），结束帧 `hid=fade`。
- 对象 `appear=<秒>` 表示它在该时间之前根本不存在（连"隐藏"都不是）。

### 3.4 开合角 `s`
只有带铰链的设备（MacBook、游戏本）能用 `s` 控制屏幕开合（单位：度，0=合上，越大越开）。手机没有铰链，`s` 写 `-`。
- MacBook：0..135，默认打开 120。
- 游戏本：0..180（180 = 完全摊平）。

### 3.5 `chain`（重绘链）
写 `chain` = 把这一帧的状态"抄"进该对象**之后的所有关键帧**。用于"这个姿势从此刻起一直保持到结尾"的场景，AI 一般不用，知道即可。

## 4. 可调用资源目录

### 4.1 设备（`model:<资产id>`）

| 资产 id | 名称 | 可开合 `s` | 可贴屏 `f` | 屏幕比例(宽/高) | 形态 |
|---|---|---|---|---|---|
| `macbook-pro-13-2020` | MacBook Pro 13" (2020) | 是，0..135 | 是，材质 `Material.002` | 1.595 | 笔记本 |
| `iphone-16-pro-max` | iPhone 16 Pro Max | 否（`s=-`）| 是，材质 `screen.001` | 0.47（竖屏）| 手机 |
| `xiaomi-17-pro-max` | 小米 17 Pro Max | 否（`s=-`）| 是，材质 `glass` | 0.456（竖屏）| 手机 |
| `gaming-laptop` | 游戏本 | 是，0..180 | 是，材质 `Material.004` | 2.17 | 笔记本 |

- 手机是**竖屏**（aspect < 1），放横图/横视频会被裁切或留边；竖图/竖视频最合适。
- 游戏本屏幕贴图贴在 `Material.004`（`Material.010` 是键盘，别贴错）。

### 4.2 字体（文字 `font=`）
`wenkai`（霞鹜文楷，中英文）、`dejavu`（拉丁）、`dejavu-bold`（拉丁粗体）。默认 `wenkai`。

### 4.3 材质预设（设备外观，非 DSL 字段，仅供了解）
`original` 原材质、`space-gray` 深空灰、`silver` 银、`gold` 金、`midnight` 午夜蓝、`ceramic` 陶瓷白、`clay` 黏土。工程文件不直接控制材质（属于 UI 编辑），AI 不需要写。

### 4.4 轨道颜色（`color=`）
可任取：`#f5a524` `#4c8dff` `#2bb673` `#e879f9` `#22d3ee` `#fb7185` `#a3e635` `#f97316`。

### 4.5 画幅（`aspect=`）
`16:9`（横屏 1.778）、`9:16`（竖屏 0.5625）、`1:1`、`4:5`（0.8）、`21:9`（超宽 2.333）。

### 4.6 默认背景
渐变：`bg=gradient color=#0b0f16 grad=#1d2534>#05070b angle=160 env=1 exp=1 shadow=0.55:2.6`。想要纯色用 `bg=solid color=#xxxxxx`；透明用 `bg=none`；媒体背景用 `bg=media bgmedia=<素材别名>`。

## 5. 约束与常见错误

1. 一行一件事；`key=value` 值内无空格；列表 `[…]`；含空格路径/名字加 `"…"`。
2. 别名先声明后使用；`@别名` 之前必须有对应声明。
3. 摄像机固定：**不要写 `@camera`**（报错"摄像机是固定的"）。
4. 合法类型只有 `model / image / video / text / media`。
5. `f=` 只能引用 §2.3 声明的素材别名，无贴图写 `-`；引用不存在的素材会跳过该帧。
6. 手机 `s=-`；只有带铰链设备才能写开合角。
7. `scene=` 值用逗号分隔（不是空格）；整体背景通常在第一个关键帧写一次。
8. 数字用小数或整数均可，但时间用秒、角度用度、opacity 用 0..1。
9. 导出视频时长 = 所有对象时间线里**最后一个关键帧的时间**（至少要有两个关键帧才有时长）。

## 6. 完整示例

### 6.1 最简：一个静止的 MacBook

```
# 简辑 · 工程文件 v1

project = 示例
aspect = 16:9
fps = 30

mac = model:macbook-pro-13-2020

@mac t=0 p=[0,0,0] s=120 a=[0,-20,0] f=- v=1 scene=bg=gradient,color=#0b0f16,grad=#1d2534>#05070b,angle=160,env=1,exp=1,shadow=0.55:2.6
```

### 6.2 手机上升并转向（运动 = 两个关键帧）

```
# 简辑 · 工程文件 v1

project = 手机展示
aspect = 9:16
fps = 30

phone = model:iphone-16-pro-max

@phone t=0.0 p=[0,0,0] s=- a=[0,0,0] f=- v=1 scene=bg=solid,color=#101418,env=1,exp=1
@phone t=2.0 p=[0,1.2,0] s=- a=[0,360,0] f=- v=[0:0.4,1:1.8]
```

> 效果：手机 0→2 秒从地面升到 y=1.2，同时绕 y 轴转一圈，缓入。

### 6.3 MacBook 屏幕播放一段视频

```
# 简辑 · 工程文件 v1

project = 宣传片
aspect = 16:9
fps = 30

intro = media:素材/intro.mp4 3.20s 1920x1080
mac = model:macbook-pro-13-2020

@mac t=0.0 p=[0,0,0] s=0 a=[0,-20,0] f=- v=1 hid scene=bg=gradient,color=#0b0f16,grad=#1d2534>#05070b,angle=160,env=1,exp=1,shadow=0.55:2.6
@mac t=0.8 p=[0,0,0] s=120 a=[0,-20,0] f=- v=[0:0.8,1:1] vis=fade
@mac t=1.2 p=[0,0,0] s=120 a=[0,-20,0] f=intro v=1
@mac.clip c1 m=intro t=1.2 in=0 out=2.8 v=1
```

> 效果：0→0.8s 合盖的 MacBook 渐隐出现，0.8s 开始打开屏幕（缓入），1.2s 屏幕点亮并开始播 `intro` 的 0~2.8s 片段。

### 6.4 文字标题渐入

```
# 简辑 · 工程文件 v1

project = 标题
aspect = 16:9
fps = 30

title = text "主标题"
  text font=wenkai size=0.6 color=#ffffff align=center content="你好，简辑"

@title t=0.0 p=[0,0.8,0] s=- a=[0,0,0] f=- v=1 hid scene=bg=none,env=1,exp=1
@title t=0.6 p=[0,0.8,0] s=- a=[0,0,0] f=- v=1 vis=fade
```

### 6.5 多设备 + 视频背景

```
# 简辑 · 工程文件 v1

project = 双机
aspect = 16:9
fps = 30

back = media:素材/bg.mp4
phone = model:xiaomi-17-pro-max
mac = model:macbook-pro-13-2020

@phone t=0.0 p=[-1.2,0,0] s=- a=[0,20,0] f=- v=1 scene=bg=media,bgmedia=back,bgfit=cover,bgoverlay=0.25,bgblur=0
@mac   t=0.0 p=[1.2,0,0] s=120 a=[0,-20,0] f=- v=1
@phone t=2.0 p=[-1.2,0.6,0] s=- a=[0,200,0] f=- v=[0:1,1:1]
```

## 7. 输出自检清单（生成后逐项核对）

- [ ] 第一行是 `# 简辑 · 工程文件 v1`。
- [ ] 每个 `@别名` 都能在声明里找到对应别名。
- [ ] 手机 `s=-`；笔记本 `s=<0..上限>`。
- [ ] `f=` 引用的别名都在素材库声明过，或写 `-`。
- [ ] 没有 `@camera`。
- [ ] 每个对象**至少两个关键帧**（否则时长为 0，视频长度为 0 秒）。
- [ ] `scene=` 用逗号分隔，且整体背景在第一帧写过。
- [ ] 含空格的路径/名字都加了双引号。
- [ ] 值内没有空格；列表用 `[a,b,c]` 且无空格。
